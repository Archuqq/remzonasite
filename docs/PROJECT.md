# Карта проекта «РЕМЗОНА»

Перед любой работой прочитай этот файл и все `docs/stage-*.md`. После этапа обязательно дополни документацию.

## Цель

Публичный одностраничный сайт премиального автосервиса **РЕМЗОНА** и закрытая админ-панель. Сайт должен быстро открываться, хорошо индексироваться и вести посетителя к звонку, а не к заявке в форме.

## Стек и почему так

| Технология                                                 | Зачем                                                                                               |
| ---------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| Next.js 16 (App Router) + React 19 + TypeScript            | Серверный рендер публичной страницы, кэш, SEO; админка в том же приложении. Не SPA на чистом React. |
| Tailwind CSS 4                                             | Утилиты и дизайн-токены из `docs/design-spec.md`.                                                   |
| next/font: Cormorant Garamond + Manrope (latin + cyrillic) | Заголовки и интерфейс по спецификации.                                                              |
| JSON-файлы + Zod                                          | Услуги, настройки и администратор в `DATA_DIR`; атомарная запись с сериализацией обновлений.          |
| sharp                                                      | Проверка/обработка фото услуг (WebP 2:1), responsive WebP/AVIF Hero.                                |
| zod                                                        | Валидация границ: env, API, формы админки.                                                          |
| bcryptjs, jose                                             | bcrypt-хеш пароля и подписанная JWT cookie-сессия администратора.                                   |
| lucide-react                                               | Единый набор тонких иконок для UI, телефона и мобильной навигации.                                  |
| npm, Node.js 20+                                           | Менеджер пакетов и runtime.                                                                         |

Не менять стек без причины и записи в этом файле.

## Принятые решения (приоритет над design-spec.md)

- **Адрес:** всегда «г. Серпухов, Советская улица, 2кА». В `design-spec.md` адрес в Москве — только демо макета, на сайте и в SEO Москву не упоминать.
- **Телефон по умолчанию:** `+7 (900) 000-00-00`, `tel:+79000000000`.
- **Часы по умолчанию:** Пн–Пт 09:00–20:00, Сб–Вс 10:00–20:00 — один источник для шапки, карты и футера.
- **Яндекс.Карты:** готовый скрипт конструктора заказчика, программно метки не рисуем. Актуальный `src`: `https://api-maps.yandex.ru/services/constructor/1.0/js/?um=constructor%3Afbeb3bf4990e6598e34b2b44941b30ec84f1a3ea38209c27403d923ae0c0887e&width=763&height=407&lang=ru_RU&scroll=true`. Смена маршрута = одна константа на этапе карты.
- **ID организации Яндекса** для отзывов: `73425839561` (`yandex_org_id` в настройках).
- **Нет формы записи и заявок.** Нет `BookingRequest`, модалки записи, `/api/bookings`, Telegram. Везде, где в макете «Записаться», — кнопка **«Позвонить»** (`tel:` на номер из настроек).
- **Фото услуг:** в seed без файлов, нейтральная заглушка. `sharp` проверяет содержимое, ограничивает вход 10 MiB/40 MP, применяет EXIF orientation и хранит две WebP-версии 2:1 (1200×600 и 600×300) под случайным UUID в `UPLOADS_DIR/services/`; UUID хранится в записи JSON. Hero WebP/AVIF и blur data URL генерируются командой `npm run images:hero` из `assets-source/hero-mercedes.png`.
- **Отзывы:** переключатель в админке; выключен — секция **не рендерится** (виджет не грузится).
- **Админка услуг (этап 4):** CRUD в `/admin/services`; фото необязательно; slug из названия только при создании; после мутаций сбрасываются `/` и тег кэша `services`.
- **Публичный shell (этап 5):** серверный route-group layout получает настройки из `getSettings()` и передаёт их Header/Footer; интерактивный мобильный menu изолирован внутри Header, публичный сайт остаётся без auth.
- **Hero (этап 6):** серверный компонент использует исходный `assets-source/hero-mercedes.png` через 4 размера AVIF/WebP, high-priority responsive preload и blur placeholder; текстовый CTA звонит по `phone_href` из настроек.
- **Главная:** Hero и metadata позиционируют сервис как «автосервис в Серпухове» без заявлений о премиум-классе. Промо-плашки и фотополосы на странице нет.
- **Гарантии:** срок гарантии на работы — 12 месяцев, на запчасти — по условиям производителя. В карточках услуг без фото используются индивидуальные тематические иконки.
- **Услуги на сайте (этап 7):** опубликованные карточки из JSON-хранилища, кэш тега `services`, кнопка «Позвонить» (`PhoneLink`); без фото — заглушка; админский предпросмотр = тот же `ServiceCard`.
- **Контентные секции (этап 8):** процесс и преимущества хранятся в `src/content`; отзывы выводятся официальным iframe Яндекс Карт только при `reviews_enabled=true`, с идентификатором из `yandex_org_id`.
- **Карта и CTA (этап 9):** URL конструктора хранится в `src/lib/map.ts`; карта загружается клиентским `MapEmbed` по IntersectionObserver с fallback-ссылкой, а финальный CTA использует `PhoneLink` и lazy hero crop.
- **Настройки сайта (этап 10):** `/admin/settings` редактирует телефон, адрес, часы, ID Яндекс, флаг отзывов и SEO-название; API пересчитывает `phone_href` и сбрасывает теги `settings` и публичный путь `/`.
- **SEO и QA (этап 11):** корневые metadata содержат canonical/Open Graph/Twitter, публичная страница добавляет JSON-LD `AutoRepair`, а `robots.ts`, `sitemap.ts` и `icon.svg` обслуживают поисковую индексацию. Lighthouse и файловый runtime smoke-test требуют отдельного окружения.
- **Хранилище (этап 14):** PostgreSQL и Prisma удалены. `services.json`, `settings.json` и `admin.json` хранятся в `DATA_DIR`; настройки промо-плашки редактируются в админке, фотографии остаются в `UPLOADS_DIR`. Этапы 1 и 13 содержат только историю прежних SQL-реализаций.
- **Публичные гарантии:** подтверждён срок гарантии на работы 12 месяцев; на запчасти действуют условия производителя. Фото-полоска использует готовые кропы существующего изображения Hero до появления собственных фотографий сервиса.
- **Авторизация** только в `/admin`. На публичной странице регистрации нет.

Источник визуала: `docs/design-spec.md` (цвета, сетка, типографика, секции). Функциональные расхождения выше важнее макета.

## Структура папок

```
src/app/(site)/     публичная страница
src/app/(site)/layout.tsx общий публичный Header/Footer и получение настроек
src/app/(site)/privacy/consent юридические страницы-заготовки
src/app/admin/      админка
src/app/api/        route handlers
src/app/(admin-auth)/admin/login/ отдельная страница входа без навигации панели
src/app/(admin)/admin/ защищённые страницы панели и смены пароля
src/app/api/admin/  login/logout/password и CRUD услуг
src/app/(admin)/admin/services  список, создание и редактирование карточек
proxy.ts            Next.js 16 перехватчик защищённых admin маршрутов (`middleware` переименован в `proxy`)
src/app/uploads/   защищённая выдача WebP-файлов из UPLOADS_DIR
src/components/ui   общие UI-примитивы
src/components/site публичные Header/Footer, Hero, секция и карточки услуг
src/components/site/Hero.tsx серверный первый экран с responsive изображением и CTA
src/components/site/MapEmbed.tsx клиентская lazy-загрузка скрипта карты
src/components/site/MapSection.tsx контактная карточка и карта
src/components/site/FinalCta.tsx финальный CTA со звонком и изображением
src/components/site/LocalBusinessSchema.tsx JSON-LD AutoRepair из настроек сайта
src/content/             статичные данные процесса и преимуществ
src/components/admin админка
src/components/admin/SettingsForm.tsx форма настроек сайта
src/lib/            env, auth, JSON-хранилище, images, settings, validation
src/lib/map.ts       единый URL скрипта конструктора Яндекс.Карт
src/app/robots.ts, sitemap.ts, icon.svg SEO-служебные файлы
scripts/            генерация Hero-версий и тесты конвейера изображений
docs/               документация этапов
assets-source/      исходники (Hero)
```

Алиас импортов: `@/*` → `src/*`.

## Соглашения по коду

- TypeScript `strict`.
- На границах (env, API, ввод админки) — zod.
- Комментарии на русском, где логика неочевидна.
- Не использовать абсолютный чёрный `#000000` и красные акценты «автосервисного» стиля.
