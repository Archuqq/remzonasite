# Этап 9 — Карта и финальный CTA

## 1. Что сделано

- Добавлена секция контактов с готовым скриптом конструктора Яндекс.Карт.
- URL конструктора вынесен в одну константу `src/lib/map.ts`.
- Скрипт карты загружается только при приближении секции к viewport через `IntersectionObserver` с `rootMargin: 400px`.
- Добавлена контактная карточка с адресом, телефоном, часами и ссылками на поиск/маршрут в Яндекс Картах.
- Добавлен финальный тёмный CTA с прямой кнопкой `tel:` и lazy-изображением автомобиля.
- Главная теперь имеет порядок: Hero → услуги → процесс → преимущества → отзывы → карта → CTA → Footer.

## 3. Как это работает

### Карта

`YANDEX_MAP_CONSTRUCTOR_URL` в `src/lib/map.ts` содержит текущую ссылку заказчика:

```text
https://api-maps.yandex.ru/services/constructor/1.0/js/?um=constructor%3Afbeb3bf4990e6598e34b2b44941b30ec84f1a3ea38209c27403d923ae0c0887e&width=763&height=407&lang=ru_RU&scroll=true
```

При обновлении маршрута или меток в конструкторе достаточно заменить значение этой константы.

`MapEmbed` — единственный Client Component этапа. На сервере он отдаёт зарезервированный блок карты, а после hydration:

1. создаёт `IntersectionObserver` с `rootMargin: "400px 0px"`;
2. при приближении карты создаёт один `<script async charset="utf-8">` с URL из `map.ts`;
3. добавляет скрипт в отдельный пустой imperative host внутри контейнера карты, поэтому React не конфликтует с DOM-мутациями конструктора;
4. не добавляет второй скрипт, если в контейнере уже есть маркер `data-remzona-map`;
5. при размонтировании отключает observer и очищает только imperative host, что корректно для StrictMode;
6. при ошибке загрузки показывает ссылку «Открыть в Яндекс Картах».

До загрузки карта имеет фон `#F2F2F0` и фиксированную высоту: `450px` на mobile, `520px` на tablet и `560px` на desktop. Это резервирует место и не допускает layout shift. Сам конструктор задаёт внутренний размер `763×407`; внешний адаптивный контейнер растягивается на ширину секции и обрезает переполнение.

После вставки конструктора его сгенерированный iframe/контейнер получает scoped-правила для `[data-remzona-map-host]`: `width: 100%` и `height: 100%` с `!important`, поэтому исходные inline-размеры `763×407` не оставляют серую область справа.

### Контактная карточка

`MapSection({ settings })` получает полный `SiteSettings` из серверной страницы. Адрес, телефон, часы и `phoneHref` не дублируются в компоненте.

Ссылка «Построить маршрут» формируется по адресу:

```text
https://yandex.ru/maps/?mode=search&text={encodeURIComponent(address)}
```

Она открывается в новой вкладке с `rel="noopener noreferrer"`. На desktop карточка размещается поверх карты слева. На mobile карточка находится перед картой и не перекрывает её.

### Финальный CTA

`FinalCta({ phone, phoneHref })` использует `PhoneLink` с вариантом `light`, поэтому кнопка ведёт напрямую на актуальный `tel:` номер из настроек. Изображение загружается лениво через локальный `hero-640.webp` / `hero-1024.webp` / `hero-1600.webp` srcset, с отдельным crop и затемняющим overlay.

## 4. Интерфейсы

Новых HTTP API и таблиц БД нет.

```ts
MapSection({ settings: SiteSettings }): JSX.Element
MapEmbed({ mapUrl: string, fallbackUrl: string }): JSX.Element
FinalCta({ phone: string, phoneHref: string }): JSX.Element
```

Источники данных:

- `settings.address` — отображаемый адрес и параметр поиска;
- `settings.phone` — видимый номер;
- `settings.phoneHref` — `tel:` для телефона и CTA;
- `settings.hoursWeekdays`, `settings.hoursWeekend` — режим работы;
- `YANDEX_MAP_CONSTRUCTOR_URL` — URL внешнего скрипта карты.

## 5. Переменные окружения и команды

Новых переменных окружения нет. Используются существующие настройки БД и `.env`.

```bash
npm run lint
npm run typecheck
npm run build
```

Для ручной проверки страницы нужен запущенный MySQL с миграциями и seed.

## 6. Принятые решения и отклонения от плана

- Скрипт добавляется вручную через `document.createElement` в `useEffect`, потому что конструктор вставляет карту на место самого script-тега и требует контейнерного поведения.
- Использован один Client Component только для карты; карта не грузится на первом экране и не требует глобального подключения стороннего скрипта.
- На mobile контактная карточка вынесена перед картой; на desktop она визуально накладывается слева.
- Fallback-ссылка отображается до успешной загрузки карты и при ошибке. Это даёт рабочий путь даже при блокировщике, сетевой ошибке или недоступности Яндекса.
- Для CTA используется существующий набор оптимизированных Hero-файлов; `hero-1024.webp` является отдельным lazy responsive вариантом, оригинал не дублируется.

## 7. Как проверить

1. Запустить MySQL, выполнить миграции и seed, затем `npm run dev`.
2. Открыть `/` и перейти к `#contacts`: после отзывов видна карта с контактной карточкой.
3. До приближения к карте проверить, что внешний script Яндекса не загружен.
4. Прокрутить к карте и проверить, что в контейнер добавляется один script конструктора, а карта появляется без скачка layout.
5. Временно заблокировать `api-maps.yandex.ru` или отключить сеть: ссылка «Открыть в Яндекс Картах» должна оставаться доступной.
6. Проверить «Построить маршрут»: новая вкладка открывает поиск по адресу из настроек.
7. Проверить телефон в карточке и CTA: оба используют актуальный `tel:` из `phone_href`.
8. Проверить порядок секций: Hero → услуги → процесс → преимущества → отзывы (если включены) → карта → CTA → Footer.
9. Проверить ширины 375, 768, 1280 и 1440 px: нет горизонтального скролла; карточка на mobile не перекрывает карту.
10. Выполнить `npm run lint`, `npm run typecheck`, `npm run build`.

## 8. Ограничения и что нужно знать на следующих этапах

- Карта зависит от внешнего конструктора Яндекса и может быть недоступна из-за сети, блокировщика или CSP; fallback ведёт на обычный поиск в Яндекс Картах.
- Внутреннее соотношение карты задаётся самим конструктором `763×407`; приложение не рисует собственные метки, въезд или маршрут.
- Точный LCP/CLS и визуальные проверки через браузер на этом этапе не измерялись.
- При смене URL конструктора нужно обновить только `src/lib/map.ts`, затем выполнить production build.
- Секция `#contacts` теперь занята картой; следующие этапы не должны возвращать пустой якорь вместо неё.
