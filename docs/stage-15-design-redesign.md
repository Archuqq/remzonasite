# Этап 15 — Тёмный automotive редизайн

## Что изменено

- Публичный shell переведён на тёмную графитовую тему с оранжевым акцентом; тема ограничена `(site)` layout и не меняет админку.
- Общие Tailwind-токены `bg-surface`, `text-ink`, `text-muted`, `bg-section-alt` и `border-line` переопределены только внутри `.site-theme`, чтобы компоненты из старого светлого дизайна не сохраняли белые карточки и тёмные заголовки.
- Hero использует `public/images/back_bmw.png`, а готовый `banner.png` после Hero работает как телефонная ссылка.
- Карточки услуг уплотнены и сохраняют данные, цены, порядок, загрузки фото и телефонные действия.
- Добавлены симптом-блок, trust-секция, бренды и mobile action bar.
- Существующие iframe отзывов и lazy карта Яндекса сохранены и адаптированы по оформлению.

## Важные решения

- Форма «записаться за 30 секунд» не реализована. Нет полей контакта, заявки, booking API или обратного звонка: все действия записи ведут на `phoneHref`.
- Акция берётся из готового `public/images/banner.png`; CTA ведёт к звонку, изображение не перекрывается повторным текстом на desktop. На mobile есть текстовая адаптация изображения.
- Фон блока доверия — `public/images/доверяют.png`; выводятся только подтверждённые факты: 12 месяцев гарантии на работы, более 10 лет из существующего контента и согласование цены до ремонта.
- Марки автомобилей показаны монохромным текстом без внешних логотипов.
- Отдельная фотогалерея не добавлена: локальных разных реальных кадров недостаточно для сетки из 6–8 фотографий. В карточках без своего фото остаются категорийные иконки.
- В локальном `UPLOADS_DIR` проверено наличие лишь четырёх файлов вариантов; полноценную галерею не создаём из повторных размеров одного кадра.
- Отзывы не копируются в фиктивные карточки: сохранены существующий cross-origin iframe Яндекс Карт, `reviewsEnabled` и внешняя ссылка.
- Карта не переписана: сохранены `YANDEX_MAP_CONSTRUCTOR_URL`, IntersectionObserver и fallback.
- В настройках часы выходных необязательны; при пустом значении строка скрыта в Footer/карте, weekend `OpeningHoursSpecification` не выводится.
- Удалены интерфейс и API смены пароля в админке; ручное восстановление доступно оператору сервера через hash utility и `DATA_DIR/admin.json`.

## Секции и навигация

На главной: Header → Hero → promo → симптомы → услуги/цены → доверие → марки и звонковый CTA → этапы ремонта → преимущества → отзывы → карта/контакты → телефонный CTA → Footer.

Header/Footer ссылаются на существующие ids: `#services`, `#about`, `#promo`, `#reviews`, `#contacts`. «Цены» ведут к текущему списку услуг; отдельная статическая копия прайса не создаётся. На мобильном фиксированная панель предлагает только «Позвонить» и «Услуги», учитывает safe area и компенсируется нижним padding.

## Проверка

- `npm run lint`, `npm run typecheck`, тесты `auth`, `services`, `images`, `storage` и `npm run build`.
- Проверены viewport 375×812, 390×844 и 1440×1000: нет горизонтального переполнения, заголовок услуг попадает в первый экран на телефоне.
- Нужно дополнительно проверить на публичном домене фактическую доступность внешнего виджета отзывов и конструктора Яндекс.Карт.
