# Техническое задание на разработку сайта автосервиса «РЕМЗОНА»

## 1. Общая концепция

Необходимо разработать одностраничный сайт премиального автосервиса «РЕМЗОНА».

Основная задача сайта — сформировать ощущение современного, профессионального и технологичного автосервиса и привести пользователя к записи на обслуживание.

Сайт должен выглядеть дорого, минималистично и современно.

Необходимо избегать типичного визуального стиля автосервисов:

* ярко-красных элементов;
* большого количества баннеров;
* перегруженных градиентов;
* дешёвых стоковых фотографий;
* большого количества иконок;
* визуального шума;
* огромного количества текста;
* агрессивных рекламных элементов.

Основное визуальное направление:

**светлый premium automotive / minimalism.**

Главная идея:

> Много воздуха + качественная фотография автомобиля + строгая типографика + аккуратные карточки + графитовые акценты.

### Плановое ТО

Замена масла, фильтров, проверка основных узлов.

### Тормозная система

Диагностика и ремонт тормозной системы, замена колодок и дисков.

### Подвеска

Диагностика и ремонт амортизаторов, рычагов, сайлентблоков.

Восстановление геометрии, устранение повреждений и покраска.

## Важно

Отзывы не нужно вручную копировать в HTML.

Использовать официальный виджет отзывов Яндекс Карт либо другой допустимый официальный способ интеграции.

Яндекс предоставляет отдельный виджет отзывов организации для размещения на сайте.

Это важно, потому что отзывы должны оставаться актуальными и подтягиваться из карточки организации.

transform:

мягкая тень.

фон немного светлее/темнее.

# 32. Главное требование к дизайну

Сайт должен восприниматься не как «сайт автосервиса», а как **сайт премиального автомобильного бренда**.

Пользователь должен открыть страницу и увидеть:

**качество → порядок → профессионализм → доверие → простую запись.**

Главный визуальный акцент — фотография автомобиля и пространство вокруг неё.

Основная цветовая формула:

**#F7F7F5 — основной фон**

**#FFFFFF — карточки**

**#15191C — текст и основные кнопки**

**#687078 — вторичный текст**

**#E5E7E8 — границы**

**#B5A98A — минимальный премиальный акцент**

При этом цвет не должен конкурировать с фотографиями автомобилей.
